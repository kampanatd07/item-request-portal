# Product

## Register

product

## Users
- **Plant requesters** (CBD, APM, APG, ACM): staff who open new non-stock and
  service items often, on office/plant desktop PCs. Moderately comfortable
  with computers; they make input mistakes often (wrong category, name
  stuffed with brand/size, wrong unit). Job: get the item requested correctly
  the first time and see where it stands without asking.
- **Procurement** (1–2 people): use the queue all day. Job: check duplicates,
  fix category/name, approve or ask for info, issue codes, export files.
- **Administrators**: occasional; snapshots, reference data, accounts.

## Product Purpose
Replace Microsoft Forms + manual checks with one place where a request is
checked for duplicates, given a standard name and a central code, and
exported to AX/D365. Success: fewer wrong or duplicate requests, fewer
"is my item ready?" questions, Procurement time per item under a minute.

## Brand Personality
Modern, friendly, uncomplicated (ทันสมัย เป็นมิตร ไม่ซับซ้อน). Speaks plain
Thai; tells the user what to do next. Carries the existing Carabao-group
green as its one brand color.

Reference: **Notion** (Peter, 2026-11-09): a quiet sidebar, a white canvas,
large page titles, light dividers instead of heavy boxes, gray hover rows,
small stroked icons. Borrow that calm and spacing, not Notion's own look.

## Anti-references
- AX/D365 screens: dense grey grids, every field the same weight, no guidance.
- The current portal: default-looking boxes, colors hardcoded per page,
  status that has to be read rather than seen.
- Generic SaaS templates: hero metrics, card grids, gradients, decoration
  that does not help finish the task.

## Design Principles
1. **Prevent the mistake, don't just report it.** Guide input at the field
   (examples, hints, suggestions) so a wrong request is hard to send.
2. **Status at a glance.** Where a request stands and who acts next should
   be visible without reading.
3. **One task per screen.** Each page has an obvious primary action; the
   rest steps back.
4. **Thai first.** Typography, spacing and copy are tuned for Thai text.
5. **Calm modern, not decorative.** Modern through clarity, type and
   spacing, not effects.

## Accessibility & Inclusion
WCAG 2.2 AA: contrast ≥ 4.5:1 for text, visible keyboard focus, labels
tied to every input, status never shown by color alone, respects
prefers-reduced-motion. Desktop-first; must stay usable at narrow widths.
